# Modern Times ウェブサイト ドキュメント

## バージョン
v1.0.0

## 概要
Modern Timesウェブサイトは、ケーキ専門店のECサイトです。
商品の閲覧・購入、レビュー投稿、お知らせの確認などの機能を提供します。

## 技術スタック
- フロントエンド: Next.js
- スタイリング: Tailwind CSS
- バックエンド: Next.js API Routes
- データベース: PostgreSQL
- ORM: Prisma
- 認証: NextAuth.js
- 画像ストレージ: Cloudinary

## 動作環境
- Node.js: v18.0.0以上
- PostgreSQL: v15.0以上
