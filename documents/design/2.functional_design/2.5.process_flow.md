# プロセスフロー設計書

## 1. 会員登録プロセス

### 1.1 会員登録フロー
```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Frontend as フロントエンド
    participant API as APIサーバー
    participant DB as データベース
    participant Mail as メールサーバー

    User->>Frontend: 会員登録フォーム表示
    Frontend->>API: 会員登録リクエスト
    API->>DB: ユーザー情報保存
    API->>Mail: 確認メール送信
    Mail->>User: 確認メール受信
    User->>Frontend: メール内のリンクをクリック
    Frontend->>API: メール確認リクエスト
    API->>DB: アカウント有効化
    API->>Frontend: 登録完了レスポンス
    Frontend->>User: 完了画面表示
```

### 1.2 エラーハンドリング
1. メールアドレス重複
2. バリデーションエラー
3. メール送信失敗
4. 確認期限切れ

## 2. 商品購入プロセス

```mermaid
sequenceDiagram

    participant DB as データベース
```

## 3. 在庫管理プロセス

### 3.1 在庫更新フロー
```mermaid
sequenceDiagram
    actor Admin as 管理者
    participant AdminUI as 管理画面
    participant API as APIサーバー
    participant DB as データベース
    participant Queue as ジョブキュー

    Admin->>AdminUI: 在庫数更新
    AdminUI->>API: 更新リクエスト
    API->>DB: 在庫情報更新
    API->>Queue: 在庫通知ジョブ登録
    Queue->>DB: 関連商品更新
    API->>AdminUI: 結果返却
    AdminUI->>Admin: 完了メッセージ表示
```

### 3.2 在庫アラートフロー
```mermaid
sequenceDiagram
    participant Batch as バッチ処理
    participant DB as データベース
    participant Queue as ジョブキュー
    participant Mail as メールサーバー
    actor Admin as 管理者

    Batch->>DB: 在庫チェック
    DB->>Batch: 在庫情報取得
    Batch->>Queue: アラートジョブ登録
    Queue->>Mail: アラートメール送信
    Mail->>Admin: メール受信
```

## 4. 決済処理プロセス

### 4.1 クレジットカード決済フロー
```mermaid
sequenceDiagram
    actor User as ユーザー
    participant Frontend as フロントエンド
    participant API as APIサーバー
    participant Payment as 決済サービス
    participant DB as データベース
```

### 4.2 決済エラーハンドリング

2. 残高不足
3. 決済サービス障害
4. タイムアウト

## 5. 配送管理プロセス

### 5.1 配送手配フロー
```mermaid
sequenceDiagram
    participant Batch as バッチ処理
    participant DB as データベース
    participant Shipping as 配送サービス
    participant Mail as メールサーバー
    actor User as ユーザー

    Batch->>DB: 未発送注文取得
    DB->>Batch: 注文情報
    Batch->>Shipping: 配送依頼
    Shipping->>Batch: 配送受付
    Batch->>DB: 配送情報更新
    Batch->>Mail: 発送通知メール
    Mail->>User: メール受信
```

### 5.2 配送状況更新フロー
```mermaid
sequenceDiagram
    participant Shipping as 配送サービス
    participant API as APIサーバー
    participant DB as データベース
    participant Mail as メールサーバー
    actor User as ユーザー

    Shipping->>API: 状況更新Webhook
    API->>DB: 配送状況更新
    API->>Mail: 状況更新通知
    Mail->>User: メール受信
```
