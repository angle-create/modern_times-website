# レビュー投稿ガイド

## 概要
商品の購入後、レビューを投稿することができます。
他のお客様の参考になるよう、商品の感想や評価をぜひお寄せください。

## レビューの投稿方法

### 1. 商品ページへのアクセス
1. 商品一覧から対象の商品を選択
2. 商品詳細ページの「レビューを書く」ボタンをクリック

```
TODO: 商品詳細ページのスクリーンショットを追加
想定する画像：
- 商品詳細ページの全体像
- レビュー投稿ボタンの位置
```

### 2. レビューフォームの入力
1. 評価（星の数）を選択
   - 1〜5段階で評価
   - 星をクリックして選択

2. レビューコメントを入力
   - 商品の感想や使用した感想を記入
   - 1000文字まで入力可能

3. お名前とメールアドレスを入力
   - 表示名として使用されます
   - メールアドレスは非公開です

4. 画像の添付（任意）
   - 商品の写真を添付できます
   - 「画像を選択」ボタンから選択

```

- 画像アップロード機能
```

### 3. レビューの送信
1. 入力内容を確認
2. 「投稿する」ボタンをクリック
3. 送信完了メッセージの確認

## 注意事項

### レビュー投稿のガイドライン
1. 実際に購入・使用した商品についてのみレビューを投稿してください
2. 事実に基づいた客観的な評価をお願いします
3. 他のお客様の参考になるよう、具体的な感想を記載してください

### 禁止事項
1. 誹謗中傷や不適切な表現の使用
2. 商品と関係のない内容の投稿
3. 個人情報の記載
4. 著作権を侵害する画像の使用

### 画像投稿について
1. 投稿可能なファイル形式
   - JPEG
   - PNG
   - WebP

2. ファイルサイズ制限
   - 1ファイルあたり5MB以下

3. 画像の内容
   - 商品に関連する画像のみ
   - 個人を特定できる画像は避ける

## レビューの公開までの流れ
1. レビューの投稿
2. 管理者による内容確認
3. 承認後にサイトに公開

※承認には通常1-2営業日かかります

## よくある質問

### Q1: レビューはいつ公開されますか？
A: 管理者による確認後、1-2営業日以内に公開されます。

### Q2: 投稿したレビューを修正できますか？
A: 一度投稿したレビューは修正できません。新しくレビューを投稿してください。

### Q3: レビューを削除したい場合は？
A: お問い合わせフォームより削除をご依頼ください。

### Q4: 画像が投稿できない場合は？
A: 以下をご確認ください：
- ファイル形式が対応しているか
- ファイルサイズが5MB以下か
- インターネット接続が安定しているか
