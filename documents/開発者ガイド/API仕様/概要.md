# API仕様概要

## はじめに
Modern TimesウェブサイトのAPIは、Next.js API Routesを使用して実装されています。
各APIエンドポイントは、RESTfulな設計に基づいており、JSONフォーマットでデータを送受信します。

## 共通仕様

### ベースURL
```
開発環境: http://localhost:3000/api
本番環境: https://your-domain.com/api
```

### リクエストヘッダー
```
Content-Type: application/json
```

### 認証ヘッダー（認証が必要な場合）
```
Authorization: Bearer {token}
```

### レスポンス形式
```json
// 成功時
{
  "data": {
    // レスポンスデータ
  },
  "meta": {
    // ページネーション情報など
  }
}

// エラー時
{
  "error": {
    "message": "エラーメッセージ",
    "code": "エラーコード",
    "details": [
      // 詳細なエラー情報
    ]
  }
}
```

## API一覧

### 商品関連
- `GET /api/products` - 商品一覧の取得
- `POST /api/products` - 商品の登録（管理者用）
- `GET /api/products/{id}` - 商品詳細の取得
- `PUT /api/products/{id}` - 商品情報の更新（管理者用）
- `DELETE /api/products/{id}` - 商品の削除（管理者用）

### レビュー関連
- `GET /api/products/{id}/reviews` - 商品のレビュー一覧取得
- `POST /api/products/{id}/reviews` - レビューの投稿
- `GET /api/reviews/{id}` - レビュー詳細の取得（管理者用）
- `PUT /api/reviews/{id}` - レビューの承認/非承認（管理者用）
- `DELETE /api/reviews/{id}` - レビューの削除（管理者用）

### 注文関連
- `GET /api/orders` - 注文一覧の取得（管理者用）
- `POST /api/orders` - 注文の作成
- `GET /api/orders/{id}` - 注文詳細の取得
- `PUT /api/orders/{id}` - 注文状態の更新（管理者用）

### お知らせ関連
- `GET /api/news` - お知らせ一覧の取得
- `POST /api/news` - お知らせの作成（管理者用）
- `GET /api/news/{id}` - お知らせ詳細の取得
- `PUT /api/news/{id}` - お知らせの更新（管理者用）
- `DELETE /api/news/{id}` - お知らせの削除（管理者用）

### その他
- `POST /api/upload` - 画像アップロード（管理者用）
- `GET /api/statistics` - 統計情報の取得（管理者用）

## 認証と認可

### 認証方式
- NextAuth.jsを使用
- JWTベースの認証
- セッション管理

### 権限レベル
1. 未認証ユーザー
   - 商品一覧・詳細の閲覧
   - お知らせの閲覧
   - レビューの閲覧

2. 認証済みユーザー
   - レビューの投稿
   - 注文の作成
   - 自身の注文履歴の閲覧

3. 管理者
   - すべての操作が可能
   - 管理者用APIへのアクセス権限

## エラーハンドリング

### HTTPステータスコード
- 200: 成功
- 201: 作成成功
- 400: リクエストエラー
- 401: 認証エラー
- 403: 権限エラー
- 404: リソース未検出
- 500: サーバーエラー

### エラーレスポンス例
```json
{
  "error": {
    "message": "バリデーションエラー",
    "code": "VALIDATION_ERROR",
    "details": [
      {
        "field": "price",
        "message": "価格は0以上の数値を入力してください"
      }
    ]
  }
}
```

## レート制限
- 未認証ユーザー: 60リクエスト/分
- 認証済みユーザー: 120リクエスト/分
- 管理者: 300リクエスト/分

## データ形式

### 日時形式
- ISO 8601形式を使用
- 例: `2024-02-20T10:30:00Z`

### 画像URL
- Cloudinaryの完全なURLを使用
- 例: `https://res.cloudinary.com/your-cloud-name/image/upload/...`

### 金額
- 日本円（JPY）
- 整数値（小数点なし）

## セキュリティ

### データ保護
- センシティブなデータの暗号化
- パスワードのハッシュ化
- HTTPS通信の強制

### CORS設定
- 許可されたオリジンからのリクエストのみ受付
- プリフライトリクエストの処理

### 入力検証
- すべてのリクエストデータをバリデーション
- SQLインジェクション対策
- XSS対策

## パフォーマンス最適化

### キャッシュ
- 商品一覧のキャッシュ
- お知らせ一覧のキャッシュ
- レビュー一覧のキャッシュ

### ページネーション
- デフォルトのページサイズ: 20件
- 最大ページサイズ: 100件

### 画像最適化
- 画像のリサイズ
- フォーマット最適化
- 遅延読み込み

## バージョニング
現在のバージョン: v1
将来的なバージョン更新時は、以下の形式でエンドポイントを提供予定：
```
/api/v2/...
```
