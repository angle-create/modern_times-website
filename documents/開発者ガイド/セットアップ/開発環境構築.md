# 開発環境構築ガイド

## 必要要件

### ソフトウェア
- Node.js v18.0.0以上
- PostgreSQL v15.0以上
- Git

### 推奨開発環境
- VSCode
  - 推奨拡張機能：
    - ESLint
    - Prettier
    - Tailwind CSS IntelliSense
    - Prisma

## セットアップ手順

### 1. リポジトリのクローン
```bash
git clone https://github.com/angle-create/modern_times-website.git
cd modern_times-website
```

### 2. 依存パッケージのインストール
```bash
npm install
```

### 3. 環境変数の設定
1. `.env.example`ファイルを`.env`にコピー
```bash
cp .env.example .env
```

2. `.env`ファイルを編集し、必要な環境変数を設定
```env
# データベース接続情報
DATABASE_URL="postgresql://modern_times:modern_times_pass@localhost:5432/modern_times_db?schema=public"

# NextAuth.js設定
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-nextauth-secret"

# Cloudinary設定
CLOUDINARY_CLOUD_NAME="your-cloud-name"
CLOUDINARY_API_KEY="your-api-key"
CLOUDINARY_API_SECRET="your-api-secret"

# Google Maps API
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY="your-google-maps-api-key"
```

### 4. データベースの準備

#### Docker使用の場合
1. Docker Composeでデータベースを起動
```bash
docker-compose up -d
```

#### ローカルPostgreSQL使用の場合
1. PostgreSQLサーバーを起動
2. データベースとユーザーを作成
```sql
CREATE USER modern_times WITH PASSWORD 'modern_times_pass';
CREATE DATABASE modern_times_db;
GRANT ALL PRIVILEGES ON DATABASE modern_times_db TO modern_times;
```

### 5. データベースマイグレーション
```bash
npm run prisma:generate
npm run prisma:migrate
```

### 6. 開発サーバーの起動
```bash
npm run dev
```
アプリケーションは http://localhost:3000 で起動します。

## 開発用アカウントの設定

### 管理者アカウントの作成
1. データベースに管理者ユーザーを作成
```sql
INSERT INTO "User" (email, name, role) 
VALUES ('admin@example.com', '管理者', 'admin');
```

2. 管理画面（http://localhost:3000/admin）にアクセス
3. 作成したアカウントでログイン

## 開発時の注意事項

### 1. コードスタイル
- ESLintとPrettierの設定に従ってコードを記述
- コミット前に`npm run lint`を実行

### 2. データベース操作
- スキーマの変更は必ずPrismaスキーマファイルで行う
- マイグレーションファイルは自動生成されたものを使用

### 3. 環境変数
- 新しい環境変数を追加する場合は`.env.example`も更新
- 本番環境の値は別途管理

### 4. 画像アップロード
- 開発時はCloudinaryの開発環境を使用
- 画像のテスト用データは`public/images`に配置

## トラブルシューティング

### データベース接続エラー
1. PostgreSQLサービスが起動しているか確認
2. データベースのユーザー名とパスワードを確認
3. データベース名が正しいか確認

### 依存パッケージのエラー
1. `node_modules`を削除
2. `npm install`を再実行

### ビルドエラー
1. `.next`ディレクトリを削除
2. `npm run build`を再実行

## サポート
開発環境の構築に関して問題が発生した場合は、以下を確認の上で開発チームに連絡してください：
1. 使用しているNode.jsのバージョン
2. 発生しているエラーメッセージ
3. 実行した手順
4. 環境変数の設定内容（機密情報を除く）
