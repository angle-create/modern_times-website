# デプロイ手順

## 概要
Modern Timesウェブサイトは、Vercelを使用して本番環境にデプロイします。
データベースはHeroku PostgreSQL、画像ストレージはCloudinaryを使用します。

## 事前準備

### 1. 必要なアカウント
- Vercelアカウント
- Herokuアカウント
- Cloudinaryアカウント

### 2. 必要な情報
- GitHubリポジトリのアクセス権限
- 各サービスのAPIキーと認証情報

## デプロイ手順

### 1. データベースのセットアップ（Heroku）

1. Heroku CLIをインストール
```bash
# Windowsの場合
winget install Heroku.CLI

# macOSの場合
brew tap heroku/brew && brew install heroku
```

2. Herokuにログイン
```bash
heroku login
```

3. PostgreSQLアドオンの追加
```bash
heroku addons:create heroku-postgresql:hobby-dev
```

4. データベースURLの取得
```bash
heroku config:get DATABASE_URL
```

### 2. Cloudinaryのセットアップ

1. Cloudinaryダッシュボードにアクセス
2. 新しいプロジェクトを作成
3. 以下の情報を取得：
   - Cloud Name
   - API Key
   - API Secret

### 3. Vercelへのデプロイ

1. Vercelにログイン
2. 「New Project」をクリック
3. GitHubリポジトリを選択
4. 環境変数の設定：
```
# データベース接続情報
DATABASE_URL="postgresql://..."

# NextAuth.js設定
NEXTAUTH_URL="https://your-domain.com"
NEXTAUTH_SECRET="your-production-secret"

# Cloudinary設定
CLOUDINARY_CLOUD_NAME="your-cloud-name"
CLOUDINARY_API_KEY="your-api-key"
CLOUDINARY_API_SECRET="your-api-secret"

# Google Maps API
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY="your-production-api-key"
```

5. 「Deploy」をクリック

### 4. データベースマイグレーション

1. Vercelダッシュボードで「Deployments」タブを選択
2. 最新のデプロイメントを選択
3. 「View Build Logs」をクリック
4. マイグレーションの実行を確認

## 本番環境の設定

### 1. カスタムドメインの設定
1. Vercelダッシュボードで「Settings」→「Domains」を選択
2. カスタムドメインを追加
3. DNSレコードを設定

### 2. SSL/TLSの設定
- Vercelが自動的にSSL/TLS証明書を提供
- 必要に応じてカスタム証明書を設定可能

### 3. 環境変数の管理
1. 本番環境用の値を設定
2. 機密情報は安全に管理
3. 定期的な更新を計画

## デプロイ後の確認事項

### 1. 基本機能の動作確認
- ユーザー認証
- 商品表示
- レビュー投稿
- 管理画面アクセス

### 2. パフォーマンスの確認
- ページ読み込み速度
- 画像の表示
- API応答時間

### 3. セキュリティの確認
- SSL/TLS証明書
- 認証機能
- 管理者アクセス

## 監視とメンテナンス

### 1. 監視項目
- サーバーの状態
- データベースの接続
- エラーログ
- アクセスログ

### 2. バックアップ
- データベースの定期バックアップ
- 設定情報のバックアップ
- 復元手順の確認

### 3. アップデート
- 依存パッケージの更新
- セキュリティパッチの適用
- 機能の更新

## トラブルシューティング

### デプロイ失敗時
1. ビルドログの確認
2. 環境変数の確認
3. 依存関係の確認

### データベース接続エラー
1. 接続文字列の確認
2. ファイアウォール設定の確認
3. SSL証明書の確認

### パフォーマンス問題
1. CDNの設定確認
2. データベースのインデックス
3. キャッシュの設定

## 緊急時の対応

### 1. ロールバック手順
1. Vercelダッシュボードで前回の正常なデプロイメントを選択
2. 「Redeploy」を実行

### 2. データベース復旧
1. 最新のバックアップを特定
2. 復元手順に従って実行
3. データの整合性を確認

### 3. 障害報告
1. 発生した問題の記録
2. 原因の分析
3. 再発防止策の検討

## サポート
デプロイに関する問題が発生した場合は、以下の情報と共に開発チームに連絡してください：
1. デプロイログ
2. エラーメッセージ
3. 実行した手順
4. 環境変数（機密情報を除く）
