# API設計書

## 1. 概要

### 1.1 基本情報
- ベースURL: `https://api.modern-times.com/v1`
- 文字コード: UTF-8
- データフォーマット: JSON
- 認証方式: JWT

### 1.2 共通レスポンスフォーマット
```json
{
  "status": "success",
  "data": {
    // レスポンスデータ
  },
  "message": "Success message"
}
```

### 1.3 エラーレスポンスフォーマット
```json
{
  "status": "error",
  "error": {
    "code": "ERROR_CODE",
    "message": "Error message"
  }
}
```

## 2. 認証API

### 2.1 ログイン
- エンドポイント: `POST /auth/login`
- 説明: ユーザー認証を行い、JWTトークンを発行

#### リクエスト
```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

#### レスポンス
```json
{
  "status": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": "uuid",
      "email": "user@example.com",
      "role": "user"
    }
  }
}
```

### 2.2 会員登録
- エンドポイント: `POST /auth/register`
- 説明: 新規ユーザーを登録

#### リクエスト
```json
{
  "email": "user@example.com",
  "password": "password123",
  "firstName": "太郎",
  "lastName": "山田",
  "phone": "090-1234-5678"
}
```

#### レスポンス
```json
{
  "status": "success",
  "data": {
    "user": {
      "id": "uuid",
      "email": "user@example.com",
      "role": "user"
    }
  }
}
```

## 3. 商品API

### 3.1 商品一覧取得
- エンドポイント: `GET /products`
- 説明: 商品一覧を取得
- クエリパラメータ:
  - `page`: ページ番号（デフォルト: 1）
  - `limit`: 1ページあたりの件数（デフォルト: 20）
  - `category`: カテゴリーID
  - `sort`: ソート順（price_asc, price_desc, created_at_desc）

#### レスポンス
```json
{
  "status": "success",
  "data": {
    "products": [
      {
        "id": "uuid",
        "name": "商品名",
        "description": "商品説明",
        "price": 1000,
        "stock": 10,
        "imageUrl": "https://...",
        "category": {
          "id": "uuid",
          "name": "カテゴリー名"
        }
      }
    ],
    "pagination": {
      "current": 1,
      "total": 10,
      "limit": 20
    }
  }
}
```

### 3.2 商品詳細取得
- エンドポイント: `GET /products/{id}`
- 説明: 商品の詳細情報を取得

#### レスポンス
```json
{
  "status": "success",
  "data": {
    "product": {
      "id": "uuid",
      "name": "商品名",
      "description": "商品説明",
      "price": 1000,
      "stock": 10,
      "imageUrl": "https://...",
      "category": {
        "id": "uuid",
        "name": "カテゴリー名"
      }
    }
  }
}
```

## 4. カートAPI

### 4.1 カート内商品追加
- エンドポイント: `POST /cart/items`
- 説明: カートに商品を追加
- 認証: 必要

#### リクエスト
```json
{
  "productId": "uuid",
  "quantity": 1
```

```json
  "data": {

      "id": "uuid",

        "name": "商品名",
        "price": 1000
      },
      "quantity": 1
    }
```
```json
  }
}
```

## 5. 注文API

### 5.1 注文作成
- エンドポイント: `POST /orders`
- 説明: 注文を作成
- 認証: 必要

#### リクエスト
```json
{
  "shippingAddress": {
    "postalCode": "123-4567",
    "prefecture": "東京都",
    "city": "渋谷区",
    "address1": "1-2-3",
    "address2": "アパート101"
  },
  "paymentMethod": "credit_card",
  "paymentDetails": {
    "cardToken": "tok_..."
  }
}
```

#### レスポンス
```json
{
  "status": "success",
  "data": {
    "order": {
      "id": "uuid",
      "status": "pending",
      "totalAmount": 1000,
      "items": [
        {
          "product": {
            "id": "uuid",
            "name": "商品名"
          },
          "quantity": 1,
          "price": 1000
        }
      ]
    }
  }
}
```

### 5.2 注文履歴取得

- 認証: 必要
- クエリパラメータ:

  - `limit`: 1ページあたりの件数（デフォルト: 20）

#### レスポンス

```json
{
  "status": "success",
  "data": {
    "orders": [
      {
        "id": "uuid",
        "status": "completed",
        "totalAmount": 1000,
        "createdAt": "2024-01-01T00:00:00Z",
        "items": [
          {
            "product": {
              "id": "uuid",
              "name": "商品名"
            },
            "quantity": 1,
            "price": 1000
          }
        ]
      }
    ],
    "pagination": {
      "current": 1,
      "total": 10,
      "limit": 20
    }
  }
}
```

## 6. エラーコード

### 6.1 共通エラー
| コード | 説明 |
|--------|------|
| INVALID_REQUEST | リクエストが不正 |
| UNAUTHORIZED | 認証が必要 |
| FORBIDDEN | 権限がない |
| NOT_FOUND | リソースが見つからない |
| INTERNAL_ERROR | サーバー内部エラー |

### 6.2 業務エラー
| コード | 説明 |
|--------|------|
| PRODUCT_OUT_OF_STOCK | 商品が在庫切れ |
| INVALID_PAYMENT | 支払い処理に失敗 |
| ORDER_ALREADY_CANCELLED | 注文がすでにキャンセル済み |
| CART_EMPTY | カートが空 |

## 7. レート制限

### 7.1 制限値
- 未認証リクエスト: 60回/分
- 認証済みリクエスト: 1000回/分
- 管理者リクエスト: 3000回/分

### 7.2 レスポンスヘッダー
```
X-RateLimit-Limit: 60
X-RateLimit-Remaining: 59
X-RateLimit-Reset: 1640995200
```
