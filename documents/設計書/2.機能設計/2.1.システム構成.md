# システムアーキテクチャ設計

## 1. システム全体構成

### 1.1 アーキテクチャ概要
```mermaid
graph TB
    Client[クライアント]
    NextJS[Next.js アプリケーション]
    API[API Routes]
    DB[(PostgreSQL)]
    Storage[Cloudinary]
    Auth[NextAuth.js]
    
    Client --> NextJS
    NextJS --> API
    API --> DB
    API --> Storage
    API --> Auth
```

### 1.2 技術スタック
1. フロントエンド
   - Next.js v14.0.0
   - React v18.2.0
   - TypeScript v5.0.0
   - Tailwind CSS v3.4.1

2. バックエンド
   - Next.js API Routes
   - Prisma v5.9.1
   - PostgreSQL v15.0

3. インフラストラクチャ
   - Vercel（ホスティング）
   - Cloudinary（画像ストレージ）
   - NextAuth.js（認証）
