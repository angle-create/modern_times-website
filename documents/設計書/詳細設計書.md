## 2. データベース設計

### 2.1 テーブル定義
#### usersテーブル
| カラム名 | 型 | NULL | キー | 説明 |
|----------|-----|------|------|------|
| id | uuid | NO | PK | ユーザーID |
| email | varchar(255) | NO | UQ | メールアドレス |
| password | varchar(255) | NO | - | パスワード（ハッシュ化） |
| name | varchar(100) | NO | - | 氏名 |
| role | varchar(20) | NO | - | 権限（user/admin） |
| created_at | timestamp | NO | - | 作成日時 |
| updated_at | timestamp | NO | - | 更新日時 |

#### productsテーブル
| カラム名 | 型 | NULL | キー | 説明 |
|----------|-----|------|------|------|
| id | bigint | NO | PK | 商品ID |
| category_id | bigint | NO | FK | カテゴリーID |
| name | varchar(200) | NO | - | 商品名 |
| description | text | YES | - | 商品説明 |
| price | integer | NO | - | 価格 |
| stock | integer | NO | - | 在庫数 |
| image_url | varchar(255) | YES | - | 商品画像URL |
| is_available | boolean | NO | - | 販売可否 |
| created_at | timestamp | NO | - | 作成日時 |
| updated_at | timestamp | NO | - | 更新日時 |

### 2.2 インデックス設計
#### usersテーブル
- email_idx: メールアドレスでの検索用

#### productsテーブル
- category_id_idx: カテゴリーでの絞り込み用
- name_idx: 商品名での検索用
- price_idx: 価格でのソート用

### 2.3 外部キー制約
- products.category_id → categories.id
- order_items.product_id → products.id
- order_items.order_id → orders.id
