# Modern Times ウェブサイト プロジェクト概要

## 1. プロジェクトの目的
### 1.1 背景
- ケーキ専門店「Modern Times」のオンラインプレゼンス強化
- コロナ禍におけるEC需要の増加への対応
- 顧客サービスのデジタル化推進

### 1.2 目的
- オンラインでの商品販売プラットフォームの構築
- ブランド認知度の向上
- 顧客満足度の向上
- 業務効率化の実現

### 1.3 期待される効果
- 売上の増加
- 新規顧客の獲得
- 既存顧客の満足度向上
- 業務コストの削減

## 3. システム概要
### 3.1 システム構成
- フロントエンド：Next.js
- バックエンド：Next.js API Routes
- データベース：PostgreSQL
- 画像ストレージ：Cloudinary
- 認証：NextAuth.js
- ホスティング：Vercel

### 3.2 主要機能
1. 顧客向け機能
   - 商品閲覧・検索
   - カート管理
   - 注文処理
   - 会員管理
   - レビュー投稿

2. 管理者向け機能
   - 商品管理
   - 在庫管理
   - 注文管理
   - 顧客管理
   - 売上分析
