# Modern Times ウェブサイト テスト設計書

## 1. テスト方針

### 1.1 テストの目的
- 機能要件の充足確認
- 非機能要件の充足確認
- 品質基準の達成確認
- バグの早期発見と修正

### 1.2 テストレベル
1. 単体テスト
2. 統合テスト
3. システムテスト
4. 受入テスト

### 1.3 テスト環境
#### 開発環境
- Node.js: v18.0.0以上
- PostgreSQL: v15.0以上
- テストフレームワーク: Jest
- E2Eテストツール: Playwright

#### テスト用ブラウザ
- Chrome
- Firefox
- Safari
- Edge

## 4. テスト実行

### 4.1 実行コマンド
```bash
# 単体テスト
npm test

# 特定のテストファイルを実行
npm test src/app/__tests__/page.test.tsx

# カバレッジレポート生成
npm test -- --coverage
```

### 4.2 CI/CD
#### GitHub Actions
```yaml
name: Test
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Setup Node.js
        uses: actions/setup-node@v2
        with:
          node-version: '18'
      - name: Install dependencies
        run: npm ci
      - name: Run tests
        run: npm test
```
